# 언령(言霊) 로그라이크 — 프로토타입 (보관)

> 이 저장소는 **처음 만든 프로토타입**을 보관한다. 본편은 [kotodama-roguelike](https://github.com/unogim4/kotodama-roguelike)에서 만든다.

한국인 학습자를 위한 히라가나 학습 로그라이크 프로토타입.
학습(서고) → 복습(습격) → 시험(보스)으로 구성된 던전을 행(行)마다 돌파한다.

👉 **플레이: https://unogim4.github.io/kotodama-prototype/**

## 담긴 것
- 히라가나 46자 · 10행 챕터 (챕터 선택 → 서고 → 무기 선택 → 습격 ×3 (45초) → 행별 요괴 보스)
- 레벨업 = 시간 정지 퀴즈 (소리→글자 / 글자→발음), 강화 3택
- 보스: 3페이즈(메아리 외침 · 메아리 바닥 · 언령 대결) + 발악 5연속, 한/영 무관 한글 입력
- 보스 10종 (야마비코 · 갓파 · 사토리 · 텐구 · 누리카베 · 바케네코 · 오니 · 야마우바 · 라이쥬 · 와뉴도)
- F2 사용자 설정 (원하는 챕터·단계로 바로 이동, 무적)
